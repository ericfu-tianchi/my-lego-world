# 评审报告 · 日本 · 京都（形态 B · 花园式立体岛）· Round 1

评审依据：`judge/JUDGE.md` v1 评分表 + `judge/briefs/kyoto.md` 设计简报
渲染图：`docs/judge/round1/01-scene.png` ~ `08-bridge-pond.png`（八张全部逐张查看）

## 1. 一句话第一印象

远看是一座认得出来的京都——五重塔的层层收分和每层勾栏确实有官方套装的影子；但镜头一推近，鸟居不对称、人仔一张脸都没有、桥上的"栏杆"是散落在路面上的圆片、草地靠随机撒点充数，**这是一张能发朋友圈的照片，不是一件能过评审的作品**。乐高玩家会为塔停留三秒，然后在特写里发现四处硬伤。

## 3. 加权总分与门禁

```
1 剪影与比例   6 × 0.20 = 1.20
2 形体准确度   4 × 0.15 = 0.60
3 技法与零件   5 × 0.15 = 0.75
4 色块         6 × 0.10 = 0.60
5 细节与收边   3 × 0.15 = 0.45
6 故事与生活   2 × 0.10 = 0.20
7 构图与层次   5 × 0.10 = 0.50
8 可拼装       6 × 0.05 = 0.30
------------------------------------
加权总分                = 4.60 / 9
```

**门禁：不通过。** 差得不近——要求每维 ≥ 8、总分 ≥ 8.5，当前八维**没有一维达到 8**，最低的两维（故事 2、收边 3）单独就压掉 1.7 分。距离入库还有两到三轮的量。

## 4. 最重要的三条修改

### 修改一：把鸟居改成一座真正对称、笠木黑且**向上**翘的鸟居

这是全岛的入口，也是简报里唯一写了"**严格**左右对称"的物件，现在三处都错：

1. **黑白关系反了。** 现在最上面一层是红梁、黑件压在它下面，所以从任何正常视角看过去，鸟居的冠部读出来是红的。改成：最顶一层 **黑色 1×12 板（60479）= 笠木**，紧贴其下 **黑色 1×12 砖（6112）= 島木**，红色只出现在柱子和贯。
2. **两端是往下掉的。** 05 图左侧能清楚看到笠木末端那块深色楔子**斜面朝下**——正好和"反り"相反。把两端各换成一块**黑色 1×2 弧形斜坡（11477）**，弧面朝外朝上安装；若想更锐一点，末端再加一枚**黑色 1×1 cheese slope（54200）**，斜面朝外上方。左右必须用同一组零件、同一朝向镜像。
3. **贯（横梁）左右出头不等长。** 02 正视图里左侧出头明显比右侧长（目测差 1–2 格）。改成一块**朱红 1×10 板（4477）**，**以两根柱子的中心线定位**（不是以梁端定位），左右各精确出 2 格。額束改成一枚 **1×1 砖（3005）**；如果柱间是偶数格、没有正中那一颗，垫一块 **jumper（15573）** 让它落在真正的中轴上。
4. 顺手清掉贯和笠木上面那排**朱红 2×2 圆片**——真鸟居的梁是光的。笠木顶面改铺**黑色 1×2 平滑砖（3069b）**。
5. 两根柱脚各加**浅灰 2×2 圆砖（3941）+ 2×2 圆片（4032）**做礎石，左右完全一致。

> 预期提升：**2 形体准确度**（解除"对称物不对称"禁忌 + 补齐笠木黑/两端上翘两条必备特征）、**1 剪影**、**5 收边**。约 20 块零件的活，性价比最高。

### 修改二：给三个人仔一张脸、一件和服、一件正在做的事

现在的 6 分维度是 2 分，而且它是**改动成本最低的一维**。

1. **脸：** 三颗头全是空白黄头，这在特写里按原样扣分，不接受"整体还行"。全部换成**有印刷的头**，这是硬性的。
2. **和服：** 把双腿换成裙摆式下身——**2×2×2 圆锥（14918）**或裙摆腿件，颜色用**白 / Dark Red**；上身配素色或带襟印刷的躯干。1:40 尺度下，"圆锥下摆 + 收窄肩线"一眼就是和服，两腿分立一眼就是牛仔裤。
3. **每人一件事（各给一个道具）：**
   - 茶室的那位：**跪坐在缘侧上**（腿件换成坐姿或直接省去，躯干坐在 1×2 板上），手持 **托盘（4523）**，盘上两枚 **1×1 圆形平滑片（98138）** 当茶碗。现在他堵在障子门口当门神，先让开。
   - 桥上的那位：手举 **雨伞（61482）**，Dark Red 色；并且**从桥顶挪到桥跨的三分之一处**、面朝五重塔——顺便把视线路径接上。
   - 石灯笼旁的那位：改成僧人（深色/藏红躯干 + 光头），手持 **扫帚（3836）**，一臂抬起，站在枯山水边缘作扫砂状。
4. 建议再补第四个：树下一位举相机的游客，或茶室檐下一位点灯的店家。现在整座岛 2,900 块只有 3 个人，太空了。

> 预期提升：**6 故事与生活感**（2 → 8 是单项最大的一次跃升，加权 +0.6）、**2 形体准确度**、**7 构图**。不动任何结构，一晚上能做完。

### 修改三：废掉"2×2 圆片撒在草上"这一招，换成真正的庭园语汇

这是全场重复次数最多的缺陷，直接压着最低的 **5 细节密度与收边**。逐项替换：

1. **飛石（踏步石）：** 草地上那些随机散落的浅灰 2×2 圆片全部撤掉，改成**浅灰 2×2 圆形平滑片（14769）**，从鸟居到缘侧连成**一条**间隔一格的踏步线，用 **jumper（15573）** 做半格偏移让它自然拐弯。石头只能在路上，不能撒在草上。
2. **石组：** 池边那圈大小一致、间距均匀的灰圆柱不是石组，是蘑菇。改成三组、每组三块、比例 3:2:1 且**互相贴靠**：一块立石用**深灰 2×2 斜坡（3039）**竖立或 1×2×2 三角砖，一块伏石用 **1×2 斜坡（3040）**，一块添石用 **1×1 cheese slope（54200）**，朝向各不相同，绝不排成一行。参考 10315 的石组是靠 SNOT 堆出来的，不是靠圆片。
3. **锦鲤：** 池里现在那几根白色圆柱像骨头。每条鲤鱼用**橙色 1×1 圆片（4073）+ 白色 1×1 圆片 + 橙色 1×1 cheese slope 作尾**，三条，头朝同一方向成群。**池子里必须出现橙色**——这是"锦鲤池"这条必备特征的判据。10315 的官方做法是印刷锦鲤 1×2 砖，可以照抄这个读法。
4. **水面：** 现在是几条深浅不一的蓝色横条，读出来是灯芯绒。照 10315 的做法：底下铺 Medium Azure / Dark Azure 板做深浅，上面盖**透明浅蓝 1×2 / 2×2 平滑砖（3069b / 3068b）**，做出深度。岸线现在是 90° 台阶，用 **2×2 四分之一圆板（27925）** 磨成弧。
5. **枯山水：** 现在是灰色、无砂纹，两条都不合格。砂必须是**白色**；砂纹用**白色 1×2 平滑砖**与**白色 1×2 格栅砖（2412）**隔行相间——格栅的棱在这个尺度下就是耙痕。深灰立石按上面 3:2:1 重新组团。

> 预期提升：**5 细节密度与收边**（3 → 7+）、**3 技法**（引入 SNOT、jumper、透明件叠层、弧形板）、**4 色块**（去掉草地上的杂色噪点、给池塘补上橙色点缀）、**2 形体准确度**（补齐石组、锦鲤、枯山水三条必备特征）。工作量最大，所以放在前两条便宜的修改之后做。

## 5. 可以保留的做法（下一轮不要改坏）

1. **五重塔每层的勾栏。** 深红板做栏台 + 朱红 1×1 圆砖当栏杆柱 + 朱红扶手，五层重复。这是全作唯一一处达到官方套装水准的细节，读得出"高欄"，别动它。
2. **竹子。** 绿色 1×1 圆砖主干 + 黄绿 1×1 圆砖做竹节 + 黄绿板做叶。零件选择完全正确。只需要把高度拉开差距（现在几根一样高），叶子从只在顶端改成两个高度都有；顺便把最靠塔的那几根往外挪 2 格，它现在长进塔檐里了。
3. **纸灯笼。** 透明橙 2×2 圆砖 + 黑色圆片，这是正确的 NPU。零件不要换，**只改挂法**：用 **1×1 带竖直夹子（60897）** 吊在檐口的 **4L 棒（30374）** 上，让它悬空。现在立在缘侧地面上，读出来像消防栓。
4. **塔的收分比例与金色相轮。** 塔高 / 岛宽 落在简报的 0.55–0.6 区间里，逐层收分的节奏是对的。下一轮不要把塔加高或压矮。
5. **塔身的白墙 + 黑色横向平滑砖。** 连子窗的读法正确，密度也刚好。
6. **池面上漂的粉色花瓣片。** 安静、正确、有季节感的小动作。保留，再加两片，并在桥下的水面也放一片。
7. **岛侧面的土层剖面（绿 → 深棕 → 中棕）。** 这个"分层地形"的想法是对的（10315 也是这么做的），问题只出在中棕那条走一半就断了——把它**整圈拉通**，收边立刻就干净了。

## 6. 逐元件评分与修复排序

| 元件 | 分数 | 一句评语 |
| --- | --- | --- |
| **五重塔** | **7** | 全作最强，五层收分 + 每层勾栏 + 金相轮基本立住；扣分在屋面是**平板**（真塔檐面是内凹下垂的）、檐角的青绿楔子是**向外摊开**而不是向上翘起、五层**层高完全相同**（真塔应逐层压矮）、塔脚直接落在草地上没有基坛和台阶。 |

| **茶室** | **4** | 障子（白板 + 深棕竖棂）、缘侧、纸灯笼三个想法都对，执行不足：**灰色屋顶踩了"灰色方盒子"禁忌**且与青绿瓦互相打架（改 Dark Turquoise 或 Dark Red）；只有一个简单双坡、没有入母屋的歇山转折、檐口薄得像张纸；**整栋房子矮于人仔尺度**——人仔的下巴已经顶到檐口，门他进不去，墙至少要抬高 2 砖。 |
| **桥与池** | **3** | 两级台阶不是太鼓桥（拱度远远不够，用 **6×1 弧形斜坡 42022** 或铰链板做出真正的半圆隆起）；**栏杆完全不存在**，取而代之的是一堆深红 2×2 圆片散落在**桥面正中**，人仔站在里面——这是全作最刺眼的一处；擬宝珠缺失（朱红 1×1 圆柱砖 3062b 顶一枚 1×1 圆片就够）；池中无橙色锦鲤、岸线是 90° 楼梯。 |
| **整体构图** | **5** | 英雄明确、地面有层次，这两点值分。但塔顶在岛的右边缘、屋檐悬出岛外没有留白，左中却空着一大片；鸟居→桥→茶室的视线中途散掉；从五层高的塔直接掉到脚踝高的散点，**缺一层中等体量**（一座钟楼、一段土塀、一片更高的松，都行）。 |

### 先修哪个（按"每小时挣多少分"排序）

1. **人仔与故事**（元件 2 分 → 目标 8）：不动任何结构，纯换头、换下身、发道具，加权直接 +0.6。**今天就能做完，先做这个。**
2. **桥与池**（元件 3 分）：元件最低分，而且它在岛的正中央，是视线离开鸟居后第一个落点。**桥面上那堆圆片今晚就要清掉**，换成真栏杆 + 真拱度 + 三条橙色锦鲤。
3. **鸟居**（元件 4 分）：简报点名的两条硬指标，约 20 块零件的活，是最便宜的一次"解除禁忌"。
4. **地面语汇**（散点 → 飛石 / 石组 / 枯山水白砂）：对最低维度"收边"的提升最大，但要一块板一块板地改，所以排在三个便宜的修改之后。顺手把岛侧面那条中断的土层拉通。
5. **樱花**：需要推倒重做骨架（枝干 + 逐朵花瓣），单位工时的收益最低——但"sakura in bloom"写在作品自己的副标题里，不能跳过。
6. **茶室**：屋顶换色 + 加一道入母屋转折 + 墙体抬高 2 砖让人仔进得去 + 灯笼改吊挂。
7. **五重塔**：已经是最强的一件，**最后动、小心动**。只做三件微调：檐面做出内凹下垂（1×3 / 1×4 弧形斜坡 50950 / 61678 + 1×2 铰链板 44302/44567，参考 21060 的做法）、逐层压低层高、塔脚补一圈浅灰基坛与三级台阶。
