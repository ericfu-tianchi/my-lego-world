## 1. 一句话第一印象

五重塔依然是全场唯一站在官方门口的一件，池面的锦鲤、睡莲、鸭子和茶室门口那张茶台也真的有人味；但这一轮的力气花在了**补拍和补小物**上，上一轮点名的三件大事——相机的手、桥、地面语汇——基本原样留着，于是整件作品还是"能认出、有亮点、硬伤多处"的 6 分样子。玩家会点赞塔和茶台，然后在 21 号图（相机怼在脸上、看不见手）划走。

## 5. 最重要的三条修改

### 修改一：把游客的相机姿势做对（10 分钟 + 一次重拍，解掉两条合规红线）

这是全包性价比最高的一处，不动任何结构。

1. **两臂都抬起前伸到相机两侧**，让**两只黄色手夹从机身左右各露出一只**——规程要的不是"手在里面"，是"渲染里看得见手夹咬住"。相机模具只有一款，不换件，只改姿势与朝向。
2. **把相机降到下巴以下一格**，现在机身压着头发（21）；真人举相机也不会把机身怼进额头。
3. **镜头轴线对准五重塔**（简报写的是"举相机看塔"），并让撑伞的女人在桥上朝他的方向走——一条视线交汇，"事件"就成立了，第 4 维还能再往上走。
4. 顺带：把他左手边那座石灯笼挪开一格，21 里他张开的手夹几乎贴着灯笼底板。

> 预期提升：解除**无穿插 / 抓握真实**两条合规；**8 可拼装**、**4 生活层**。

### 修改二：太鼓桥重做成"鼓面"，鸟居的笠木减薄

这两件在画面正中，同时压着剪影、形体、技法、构图四个维度的天花板。

1. **桥面必须拱起来**：桥中段比两端高两块板，用**朱红 1×2 与 2×2 曲面斜坡（弧面朝上）**把台阶磨成连续的鼓面弧，**全部铺光面砖，一颗裸凸点都不留**；桥腹保留现在的拱形砖。
2. **栏杆改成柱 + 扶手**：桥两侧立**朱红 1×1 圆砖（或长杆）做栏杆柱**，柱间横连一根**朱红长杆 / 1×4 光面砖做扶手**，柱顶各扣一颗**珍珠金 1×1 圆头做擬宝珠**；**把现在平躺在桥面上的所有 2×2 圆形光面砖全部撤掉**——它们既不是擬宝珠也不是路面。
3. **鸟居笠木减薄一半**：下面一道**黑色光面砖长梁做島木**，上面一道更窄的黑梁做笠木，两端各只用**一块黑色 1×2 曲面斜坡、弧面朝外朝上**表达反り；撤掉现在那两片挑出三格的大弧形件。**額束收窄成一格宽的短柱**（现在那块宽匾把中央堵死了）。
4. **把鸟居沿岛缘外移三到四格**，让它背后是天空而不是茶室——现在它的黑笠木在 13 / 24 / 27 三张图里横切主体，是拍不好的根因。

> 预期提升：**1 剪影**（桥与鸟居重新进入轮廓）、**2 形体**（太鼓桥、栏杆两条必备特征）、**3 技法**、**7 构图**。

### 修改三：把地面语汇一次做完（砂、岸、苔、散点）

纯铺板的活，一次覆盖四个维度，并解掉一条合规。

1. **枯山水扩到至少 10×8**，砂面铺白色光面砖或白色 1×1 圆板；**耙痕用浅灰格栅砖排成绕石组的连续同心弧**，一圈一圈绕过去，而不是现在这样散落三四片；**把砂里的中灰 2×2 光面砖和四颗深绿圆板全部拿掉**；石组按 3:2:1 重排，三块互相贴靠、朝向各异，再把那顶亮黄色圆锥件撤掉或换成深色的斗笠放在石边（现在读不出是什么）。
2. **池岸磨圆**：直角转角用**四分之一圆板 / 圆角砖**收两三处，岸边用**深绿 1×1 圆板 + 少量浅灰岩石**做成不规则的自然岸；水面中央换一档**更深的蓝色薄板**做深浅，现在一色到底。西岸那一堆碎石收成两组三五块的石组，其余撤掉。
3. **草地**：**把六处单独立着的黄绿卷须全部撤掉**（不在色板里）；深绿只留三四处**有理由**的苔斑——树根下、石灯笼脚下、岸边、岛缘，每处三到五块抱成团，其余恢复亮绿底。
4. **飛石**：把 12 / 22 里脱队的浅灰圆形光面砖并回那条绕池的线，间距一格、拐弯处用 jumper 做半格偏移；石头只能在路上。
5. **招牌「茶寮」改对比度**（顺手做，10 分钟）：漆黑板 + **珍珠金或白色明朝体**，字形与字距照现在这版原样保留，只翻明暗关系——这一条改完即解掉"字像印刷"。

> 预期提升：**6 收边**、**5 色块**、**2 形体**（耙痕、圆岸线两条必备特征）、**7 构图**；解除**无随机撒点**与**字像印刷**两条合规。

## 6. 可以保留的做法（下一轮不要改坏）

1. **五重塔的全套配色与层次**：灰瓦 + 白墙 + 深红木构 + 朱红勾栏 + 珍珠金相轮 + 浅灰基坛。除了檐角与正面台阶，**一块都不要动**。
2. **茶室这一件已经成立**：低而宽、深出檐、障子门、茅色屋顶、门楣挂匾、**缘侧**、人仔进得去。缘侧是这一轮补对的，保住。
3. **茶室门口那组小场景**：茶台 + 两只白茶杯 + 茶罐 + 白猫 + 三根「京」灯笼。全岛最有人味的地方，一块别减。
4. **池面的生活层**：橙 / 红 / 白三条锦鲤、睡莲、莲叶、黄鸭、绿蛙、落瓣。安静、有季节感、读得出来。
5. **笠木上那只白鸟**：全作最会心的一处 NPU。笠木重做之后把它原样搬上去。
6. **三个人仔的印花**：三件躯干（白底红领樱花和服 / 橙色袈裟僧衣 / 浅底藏青领浴衣）和两张脸（闭目微笑的僧人、露齿笑的游客）都是官方水准，别动。
7. **撑伞人与僧人的手部做法**：手夹咬杆、手臂前伸/抬起——这两处是这一轮修对的，改姿势时把这套关系原样保留。
8. **灯笼「京」的印花**：单字、明朝体、干净。招牌照这个的可读性去改。
9. **岛的三层土色带**与绕池的飛石路线走向。
10. **人数保持 3 个**。岛看着空要靠地面语汇和中层体量填，不是靠加人。
