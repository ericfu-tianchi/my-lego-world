## 1. 一句话第一印象

五重塔这一件已经站到了官方套装的门口——灰瓦、白墙、深红檩、朱红勾栏、金相轮，剪影里一眼认得出是清水寺那一路的塔；但除了塔以外，**每一件东西都还差一次收尾**：鸟居在剪影里整个消失、太鼓桥是一块裸着凸点的红砖坨、游客的手整只吞进了相机里、草地上撒着六七块没来由的黄绿方块。乐高玩家会为塔和茶室那张小茶台点赞，然后在人仔特写里划走。

| 呼吸感 | **过** | 空草地 + 水面目测 ≥ 40%；池塘约占岛面 6–7%；从 05 量，北侧樱花树冠与茶室檐口留出约 1.5 格，不相碰；三个人仔分在桥、枯山水、鸟居前三个区，没有任何 6×6 里出现两个人。唯一保留意见：**水面不"安静"**——桥那一大坨饱和朱红压在池子正上方，抢走了中心的平静。 |
| 树有枝有层次 | **不过** | 三棵樱花（13/14/15）达标线以上：细干、三到四个高度的分枝、每个枝头一团花、花团之间有空气。**但松树（03 左、05 右上、14 右）是两层平摊的深绿圆片叠在一根杆上**，正好命中"平摊的圆片层不算树"。竹子（09/13）也只是每根顶端插一到两片叶，叶量太薄。 |
| 装饰件规范 | **过** | 8 款 ≤ 12，约 10 块 ≤ 40。印花都落在平面或人仔头/躯干上；数一下颜色：游客和服 4 色（暗红、红、金、浅灰）压着上限，僧衣 3 色，招牌 2 色，都不超。不盖凸点。 |
| 比例分层 | **过（有保留）** | 茶台、茶杯、茶罐、猫、鸡、鸭、锦鲤、石灯笼都是人仔比例；地标压缩，边界清楚。保留意见：**相机（20/21）明显超尺度**，机身比人仔的头还宽、还带一个侧架，读作 1960 年代新闻摄影机而不是游客的相机。 |
| 无随机撒点 | **不过** | 三处：① **草地上六七块黄绿（lime）方块单独散着**（05 全图可数出 5–6 处，12 右侧、15 中下各一处），既不成组也不在简报色板里；② **飛石是散颗的**——07 前景两颗、09 一颗、12 一颗、05 中段三四颗，从鸟居到茶室**没有连成一条线**，简报明写"石头只在路上，不撒在草上"；③ 池岸和草地上的单颗灰岩石（07 有四颗、21 有两颗）各自为政，不成石组。 |

**合规结论：不通过。** 五条不过：无穿插 / 抓握真实 / 无内部外露 / 字像印刷 / 无随机撒点（外加树的松树一项）。其中前三条都集中在人仔上，是最便宜的一次解锁。

## 4. 加权总分与门禁

```
1 剪影与比例   6 × 0.18 = 1.08
2 形体准确度   6 × 0.15 = 0.90
3 技法与零件   6 × 0.12 = 0.72
4 生活层       7 × 0.15 = 1.05
5 色块         6 × 0.08 = 0.48
6 细节与收边   5 × 0.14 = 0.70
7 构图与层次   6 × 0.10 = 0.60
8 可拼装       6 × 0.08 = 0.48
--------------------------------
加权总分                = 6.01 / 9
```

**门禁：不通过。** 要求每维 ≥ 8 且加权 ≥ 8.5；当前**没有一维达到 8**，最低的收边只有 5。合规清单另有五条不过，即使分数够也会被直接拦下。

按锚点定位：**这是一件"能看出是什么、有一两处亮点（塔、茶台小场景）、多处硬伤"的作品**，正好落在 6 的描述上。离"资深玩家会转发的 MOC"（8）还差一轮扎实的收尾，离官方套装（9）差两轮。

## 5. 最重要的三条修改

### 修改一：把三个人仔的手和动作做对（解掉三条合规红线）

这是唯一一条**不动任何结构**、却同时拆掉"无穿插 / 抓握真实 / 无内部外露"三条红线的修改，一个晚上能做完。

1. **游客（20/21）**：把现在那台超尺度相机换成**人仔手持的小型相机件**（1×2 见方那一种，参考 `minifig-vignette.png` 里摄影师手上的那款）。**两臂都抬起前伸**，左右各一只手夹从相机两侧咬住，**黄色手夹必须在渲染里看得见**。现在的做法是把相机接在袖子末端、手整只埋进机身。
2. **僧人（18/19）**：扫帚换成**长杆细头的竹箒式扫帚件**（不要那把深红色家用推把）；**持杆手臂向前下方压到约 45°**，另一只手也上杆做双手握姿；**帚头落在白砂上**，不是落在草地上。现在扫帚竖在身侧、帚头在草地，而枯山水在他右手边两格外——"扫砂"这个动作完全没发生。顺带把扫帚杆挪开他的下巴，18 里杆子正好切过嘴。
3. **撑伞的人（15/17）**：按简报换成**女性人仔**——黑色盘发件 + **白底、红领、樱花小碎花的和服躯干印花**（现在是深蓝素躯干，深色印花压在深蓝底上等于没印）。**伞杆改成竖直，伞面正在头顶正上方**，手夹在杆的中段。
4. 三个人做完之后，给他们一个共同的落点：让游客的镜头明确指向塔，撑伞的人面朝游客的方向过桥，僧人抬头看樱花——三条视线交汇一次，"事件"就成立了。

> 预期提升：**4 生活层**（7 → 8+）、**8 可拼装**、**2 形体准确度**；并解除三条合规不过。

### 修改二：重做地面语汇——砂、飛石、苔、岸线

四件小事，全都是铺板的活，但它压着全场最低的一维。

1. **白砂（12）**：砂面改用**白色 1×1 圆板（凸点朝上）**铺满，这是官方表达"砂粒"的读法（`kyoto-composition.png` 和 `minifig-vignette.png` 都是这么做的）；**耙痕用浅灰 1×1 圆板排成绕石组的同心弧线**，一圈一圈地绕过石头，而不是现在这样只在边缘放两条灰格栅、中间留白。砂区的外轮廓用**浅灰 1×2 / 2×2 光面砖压一圈边**，把现在参差凸出的白板收齐。
2. **飛石**：草地上所有单颗的浅灰 2×2 圆形光面砖收拢，**从鸟居正下方一路连到茶室门口，排成一条间隔一格、会拐弯的连续线**（拐弯处用 jumper 做半格偏移）。石头只能在路上。
3. **苔与草斑**：**把所有黄绿（lime）方块撤掉**——不在简报色板里。改成**深绿 1×1 圆板与草丛件成组**，只长在池岸、树根、石灯笼脚下、岛缘这四类"有理由"的位置，每处三到五颗抱成一团。
4. **岸线（05）**：现在的直角矩形水带改成不规则弧线——用**深绿 / 亮绿 1×1 圆板 + 浅灰岩石件**沿水边做成锯齿状的自然岸，水面外圈用**四分之一圆板**磨圆两三个转角；池子往画面中心挪两三格，把"安静的中心"还给水。

> 预期提升：**6 细节与收边**（5 → 7+）、**2 形体准确度**（补齐耙痕、飛石、圆岸线三条必备特征）、**5 色块**（去掉草地杂色）、**7 构图**；并解除"无随机撒点"。

### 修改三：把桥瘦下来，把鸟居挪出来

这两件挤在一起、红压红，同时压着剪影、技法和构图三个维度的天花板。

1. **桥（12/17）**：桥面**通铺朱红 1×4 / 1×6 光面砖**，一颗裸凸点都不留；桥身厚度砍掉约两块砖，拱腹用**两片朱红弧形砖（arch brick）对接**成太鼓弧；桥两端的红砖踏步改成**朱红 1×2 / 1×3 斜坡砖 + 光面砖**；**栏杆柱之间必须加横扶手**——朱红 1×4 条形栏（bar）或 1×4 光面砖横连柱顶，柱顶的擬宝珠改成**珍珠金 1×1 圆头**（黑色圆头留给灯笼柱，避免一招用两处）。
2. **鸟居（07）**：往岛缘方向**挪出至少 6 格**，让它独立站在一片空草地上、背后是天空而不是红桥；柱径**减半**（1×1 圆砖叠柱 + 柱顶圆锥收头），净跨保持现状，比例立刻对；**笠木两端各加一块黑色 1×2 曲面斜坡、弧面朝外朝上**，把"反り"做到剪影里读得出来（现在 06 的剪影里整座鸟居消失）。
3. 顺手：把最高那棵樱花**加高两到三块砖，越过茶室屋脊**，中层就回来了；松树（03/05/14）现在是两层平摊的深绿圆片，改成细干 + 三根不同高度、不同方向的枝 + 每个枝头一团深绿叶，做出云片层。

> 预期提升：**1 剪影**（鸟居重新进入轮廓、中层补回）、**3 技法**、**7 构图**、**5 色块**（红体量收敛）；并解除"树有枝有层次"。

## 6. 可以保留的做法（下一轮不要改坏）

1. **五重塔的整套配色与层次**：灰瓦 + 白墙 + 深红檩 + 朱红勾栏 + 金相轮 + 浅灰基坛。这是全作唯一达到官方水准的部分，除了檐角和层高之外**不要动**。
2. **鸟居的构件完整性与严格对称**：两柱、贯左右出头等长、黑笠木在最上、額束、礎石——上一轮的三处错全改对了。挪位置和瘦柱子的时候，**这套构件关系原样搬过去**。
3. **茶室的体量与开口**：低而宽、深出檐、障子格门、人仔进得去门、「茶寮」黑匾挂在门楣正中。这一件的判断是对的，只欠一道缘侧。
4. **茶室门口那一组小场景**：茶台 + 两只白茶杯 + 茶罐 + 白猫 + 白鸡 + 三根灯笼柱。全岛最有人味的地方，密度和尺度都对，一块都别减。
5. **樱花的花团配方**：三叶圆板做结构 + 1×1 圆板做花 + 五瓣花做点缀 + 草地上的落瓣。配方正确，只需要把枝从水平板扇改成有角度的分枝、把树干做倾斜。
6. **池面的生活层**：橙色锦鲤、睡莲、黄鸭、飘落的花瓣。安静、有季节感、读得出来。
7. **岛的三层土色带**（草 / 深褐土 / 灰岩）：上一轮断色的问题已经整圈拉通了。概念保留，只收底沿。
8. **灯笼「京」的印花**：单字、明朝体、干净、读得出。招牌照这个对比度去改，而不是反过来。
9. **人数保持 3 个**。不要因为"岛看着空"再加人——空是靠地面语汇和中层体量填，不是靠人。

### 先修哪个（按"每小时挣多少分"）

1. **地面语汇**（砂纹 / 飛石 / 苔 / 岸线）——纯铺板，不动任何结构，一次覆盖 6、2、5、7 四个维度，并解掉"随机撒点"。**性价比第一。**
2. **三个人仔的手与动作**——三处局部改动，直接解掉"无穿插 / 抓握真实 / 无内部外露"三条红线，生活层再往上推一档。**一个晚上。**
3. **岛缘收边**——沿岛一圈把底沿压齐、加一道压边（岩石件或深色光面砖），出现在每一张图里，改一次全场受益。
4. **太鼓桥**——铺光面砖、减厚、加横扶手、踏步换斜坡。工作量中等，但它是画面中心，不修就一直抢戏。
5. **鸟居外移 + 瘦柱 + 反り**——把剪影里缺的那一件补回来。
6. **中层体量**——最高的樱花加高越过茶室屋脊，松树重做成云片层。
7. **五重塔的三处微调**（上翘屋角件、逐层压低层高、正面台阶）——**最后动，小心动。**

## 8. 流程问题（不计分）

1. **16-fig-parasol-front.jpg 报废**：镜头卡在黑色笠木内侧，整幅是一块黑板 + 一角红砖，看不到任何主体。规程要求每个人仔给两个角度的**能看清脸、手和道具**的特写，这个人仔实际只给到了一个侧后角度（17）。
2. **撑伞人的正面在 21 张图里一次都没有出现**。她的脸印花和「藏青和服」躯干印花我从头到尾没看见过；按规程"被遮挡就按看到的扣分"，我按"深蓝素躯干、短发男性"判的。下一轮必须补一张正面平视特写。
3. **08-bridge-pond.jpg 拍的不是桥和池**，而是五重塔的檐角与勾栏特写（构图本身很好，但文件名和评审需求对不上）。太鼓桥与锦鲤池实际只能从 12 的背景和 17 的地面推断，**桥的侧立面（拱腹 + 栏杆全长）没有任何一张正经图**。
4. **游客持相机的手在 20 和 21 两个角度都被机身挡住**。两个角度都看不见手，我按"手埋在相机里"扣分；如果实际有手，请补一张从相机另一侧（人仔左前方低角度）的图。
5. **07-torii-front.jpg 把笠木裁掉了**，无法判断两端反り的造型——这是简报点名的必备特征，正面图必须完整包含物件轮廓。上一轮也提过同样的问题。
6. **缺件**：简报点名的「缘侧」「石组」「飛石路线」都没有独立特写；建议下一轮补三张——茶室侧立面（看缘侧与檐下）、枯山水俯视（看耙痕与石组关系）、从鸟居往茶室方向的平视（看飛石是否连成线）。
7. **建议增加元件剪影**：塔以外的每件（鸟居、桥、樱花、茶室）各一张纯剪影。鸟居在场景剪影里消失这件事，如果有元件剪影会更早发现。
