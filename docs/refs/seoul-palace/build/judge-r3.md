## 5. 待解决问题（按影响排序）

1. **檐线：封檐板角内那一级台阶和角翘件（维度 1、2、3，预计 +0.6；制作方留给 Eric 定）**
   - 这是第 1 轮到第 3 轮一直扣分的同一个问题，r3-side-eave 已经证实。
   - 去掉封檐板两端那块平的砂绿方块。让倒弧下垂线一直延伸到角上：每个角最后 3–4 格，砂绿 1×2 倒弧形斜坡逐格抬高一块板。
   - 角尖：白色 1×2 弧形斜坡（弧面朝外朝上）收尖，接在封檐板的末端上，不再从一个平台上伸出去。
   - 平面上用铰链板或 2×2 圆板转 45°，让角尖沿垂脊方向指出去。
   - 判断标准：在 r3-side-eave 这个角度，檐的下沿是一条从中间往两端连续上扬的弧，看不出"台阶 + 角"。

2. **獬豸：做成一只兽（维度 4、2，预计 +0.4）**
   - 体量改成横向：长 4、宽 2，不要现在的竖方块。
   - 后半身：2×2 弧形斜坡做臀。
   - 前腿：两根 1×1 圆砖直立在前沿。
   - 胸：1×2 倒斜坡挺出。
   - 头：低于臀线以上一砖、往前探出半格。侧凸点砖上挂 1×2 格栅砖做牙，1×1 圆片做眼，2×2 曲面砖做鬃。
   - 拱件底下的空洞补实。
   - 判断标准：r3-haechi-side 这个角度能数出头、胸、前腿、臀。

3. **垂脊白线连续（维度 2、5，预计 +0.3）**
   - 在现在的白块之间，沿垂脊补满白色 1×1 光面砖或白色 1×2 弧形斜坡，让正脊端到角尖不露一格灰垄。
   - 雑像改用深蓝灰 1×1 圆锥或 1×1 圆砖加圆片的小立件，代替扁黑圆片，读成小立像而不是凸点。

4. **宫墙墙顶（维度 6，预计 +0.2）**
   - 平顶雨棚改成：深蓝灰弧形斜坡排出瓦垄，下面一排白色 1×1 圆片做瓦当。
   - 两端用 1×2 弧形斜坡收口，墙身端头加一列收边砖，不要直接截断。

5. **檐下圆点和门（维度 6、2，预计 +0.2）**
   - 斗拱带的白色 2×2 圆片换成 1×1，每格一个。
   - 拱里的暗红砖换成暗红门板，半开。
