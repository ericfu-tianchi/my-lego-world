## 1. 一句话第一印象
远看认得出"东亚双檐城门"，但还不是光化门：两层屋顶是两块差不多宽的薄板，屋面瓦垄碎成一格格的块，四角伸出水平的"角"，正是简报点名不要的"直檐加一个翘"；两只獬豸看起来像一截消防栓。乐高玩家不会转发。

## 5. 最重要的修改（前 5，按影响排序）

1. **屋面改成连续瓦垄，角翘从瓦垄本身长出来（维度 1、2、3、6，预计 +0.8）**
   - 每个坡面上，深蓝灰 1×N 弧形斜坡从屋脊一路排到檐口，排成不断开的竖垄，垄与垄之间低一块板形成瓦沟。参照 Seon-Bi Won：长垄、等距、垄头整齐。
   - 去掉现在零散的短弧形斜坡块。
   - 檐口最外一排靠侧出凸点砖（headlight 砖 / 1×1 侧凸点砖）挂白色 1×1 圆片，做瓦当。
   - 角翘：每角最后 3–4 条垄逐条抬高一块板。最末一条用深蓝灰 1×2 倒弧形斜坡托住、顶上一块 1×2 弧形斜坡朝外朝上收尖，让檐线从正中下垂处一路连续升到角尖。
   - 删掉现在水平伸出的弯角件。
   - 正立面那条砂绿封檐板的倒弧下垂线保留，屋面的檐线要贴着它走。

2. **收窄上层屋顶、拉高楼身（维度 1、2、7，预计 +0.5）**
   - 上檐总宽收到下檐的约 75–80%（例：下檐 28 格，上檐 22 格）。
   - 上层楼身加高 2–3 块板，让暗红柱、砂绿格窗（格栅砖）、匾额完整露在两层檐之间。
   - 匾额换成更大的黑色光面砖（例：1×6 换成 2×6 侧立），字放大到占匾高的 60%，让 hero 缩略图里也读得出。

3. **垂脊白线 + 雑像排成一列，屋面压深（维度 2、5、6，预计 +0.4）**
   - 每条垂脊用白色 1×2 / 1×1 光面砖或白色 1×2 弧形斜坡，沿对角线逐级铺成连续的白线，从正脊两端一直接到角尖。
   - 雑像改成每条垂脊 3–5 个深蓝灰小立件（1×1 圆锥、1×1 圆砖加 1×1 圆片），等距排成一列，越靠近角越小。去掉现在成对散落的黑圆片。
   - 屋面全部用深蓝灰，让白线跳出来。
   - 正脊两端的鸱尾保持黑色。

4. **重做两只獬豸：一只蹲坐的兽（维度 2、4，预计 +0.4）**
   - 浅蓝灰色，坐在两层石台上：4×4 砖 + 4×4 光面板，边上一圈 1×1 圆砖。
   - 身体：2×3 砖，后部用 2×2 弧形斜坡做臀；前腿是两根 1×1 圆砖，脚掌用 1×1 圆片。
   - 胸：1×2 倒斜坡。
   - 头：2×2 侧凸点砖，正面挂 1×2 格栅砖当牙，1×1 圆片当眼，1×2 弧形斜坡做朝前的口鼻，顶上 2×2 曲面砖做鬃。
   - 头朝前（朝广场），不朝侧面。照 haetae-2026 照片的坐姿：前腿直立、胸挺、头大。

5. **斗拱带、门、立面收边（维度 6、2，预计 +0.3）**
   - 斗拱带：把大号白色 2×2 圆片换成每个凸点一个白色 1×1 圆片，每层檐一排、等距、不间断。正中两个挤在一起的点要修掉。
   - 暗红、深蓝大圆片缩成 1×1，只放在柱头位置。
   - 门：竖着的暗红砖换成暗红门板（1×4×6 门或面板件），半开地挂在拱里，读成门扇。
   - 正面：删掉左墩上那块孤立的白砖；若要做排水石口，就在每个墩上对称各放一个浅灰 1×1 侧凸点砖加 1×1 光面砖。
   - 背面胸墙补上和正面一样的白框面板。
   - 墙段端头加一个 1×1 收口，墙顶用深蓝灰 1×2 弧形斜坡排出瓦的节奏。

## 6. 可以保留的做法
- 砌石纹砖做花岗岩基座，拱件做的拱顶（r1-haechi、r1-front），质感对。
- 中拱大、两侧拱小，比例关系对。
- 砂绿封檐板用倒弧做出的下垂曲线（r1-plaque 上层檐下沿），这是全件最接近简报的一笔，屋面要贴着它改，不要拆掉。
- 胸墙"白色光面砖 + 白色格栅砖"交替的白框面板。
- 匾额：黑底金字、从右往左读、楷书风。
- 7 色的克制配色，暗红柱、砂绿带的用色对实物。
- 四角对称（v1-top）。
