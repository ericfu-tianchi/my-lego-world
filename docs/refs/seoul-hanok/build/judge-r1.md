# 裁判报告 · 首尔 · 北村元件（韩屋 + 胡同 + 邻家屋顶 + 银杏）· 第 1 轮

规程：judge/JUDGE.md v5。锚点：LA v3 = 9（17 张）、Prague v3 = 8（23 张），逐张对照后打分。
渲染包：d5-hero、p-south、p-east、d5-alley、p-eave、hip-r3-corner、p-ginkgo、p-top。参考：seoul-hanok-lego.png、real-bukchon-01/05、moc-ideas-seonbiwon、real-ginkgo-autumn。
不评：灰色底板、测试用土块、应用界面、尺寸样本小银杏（只看它在不在凸点上）。

## 1. 第一印象
一眼能看出是东亚瓦顶院落，瓦当白点、灰砖台基上的回纹花墙和蜂蜜色圆柱把方向拉向了韩国，这条路选对了。但屋面是笔直的斜板，瓦垄之间露着一片片凸点，檐口椽头疏密乱，门窗没有窗棂格，院里空着。乐高玩家会点赞这个思路，但不会转发，现在更像结构草稿，不像能上架的成品。

## 5. 最重要的修改（按收益排序；前三条为必改）
1. **把瓦垄沟铺平，再把檐口做出曲线**（维度 1、3、6，预计 +0.6）。每条瓦垄之间的沟铺深灰光面 1×N tile 当仰瓦，屋面上不能再露一颗凸点。每个转角最后 2～3 条瓦垄改装在铰链板或楔形板上，逐条抬高 1～2 层板，做出起翘。四条戗脊用深灰 1×2 弧形斜坡沿角线叠一条凸起的脊，脊端放一枚白色 1×1 圆板。转角两侧必须对称，先拿 hip-r3-corner 测试件做到对称，再推到整栋。
2. **补上方格窗棂和真正的大门**（维度 2、3，预计 +0.4）。主屋正面和门屋窗户：白色背板前面装 Tan 或 Medium Nougat 的方格栅栏件（1×4 方格栅栏或方格窗扇，侧装 SNOT），每间一扇，等分开间。门屋大门换成两扇带木纹竖板的门板，门钉用黑色 1×1 圆板点一列，门环用黑色带环的小件挂在门板中缝两侧。
3. **椽头等距，并清理所有毛边**（维度 6、8，预计 +0.35）。下排椽头白圆 tile 改成一格一个、等距单排，压在下挂支架的正面，不错位、不成簇。邻家山面两块斜挂的深红件，要么换成支架或夹子固定的博风板收头，要么直接拆掉。胡同东侧那列裸凸点铺 tile；邻家墙角那块孤立的橙色砖换成白墙或花岗岩色。
4. **给院子和胡同放人仔比例的小物**（维度 4，预计 +0.3）。院里角落放一组酱缸台：3～5 个 Reddish Brown / Dark Brown 圆砖加圆顶做成的缸，大小错开，立在一块浅灰石台上。大门旁挂一块蓝底白字的门牌（印花，只印门牌号）。门屋前放一条木色长凳（参考图里就有）。烟囱要出现在主视角里，现在任何一张图都认不出它。
5. **银杏抬高、加密，并和屋顶拉开距离**（维度 7、1，预计 +0.2）。树干再加 3～4 层，让树冠整体高出主屋脊至少 1/3 树高，同时离两处屋檐都 ≥ 1 格。树冠内层用黄色小叶件或 1×1 圆板加密，让它读成实心的蛋形冠，不要读成一捆带圆头的枝条。落叶 tile 一律正放在凸点上，集中在树下一圈，院内那两三片孤立的拿掉。

## 6. 可以保留的做法
- 回纹花墙压在花岗岩台基上：印花干净、比例对，是这个元件最"韩"的一笔。花墙底色改成砖红即可，图案不要动。
- 支架托白圆 tile 做瓦当、下挂支架做深红檐板：方向和 Seonbiwon MOC 一致，加了仰瓦以后会更好看。
- 屋脊的白线加两端弧形翘头：形状对，别改成尖翘。
- 蜂蜜色圆柱，单轴叠起来，开间等分。
- 胡同台阶：平板等高、同色，铺地带缝的质感正好。
- 三级体量（主屋 > 门屋 > 邻屋）和顺坡而上的胡同。

## 7. 多元件排序
只有一个元件，不排序。元件内部先修哪块（按每小时挣分）：屋面仰瓦和起翘（第 1 条）> 毛边清理（第 3 条，便宜）> 窗棂和大门（第 2 条）> 院内小物（第 4 条）> 银杏（第 5 条）。
