# 洛杉矶岛 · 整岛评审 第 1 轮（JUDGE v4）

评审依据：judge/JUDGE.md v4；8 分锚点 = 京都 v10（30 张逐张对照）；简报 judge/briefs/la.md；渲染包 v3-*（16 张）；参考 la-composition.png 与 la-*-lego.png。

## 1. 第一印象
一眼认得出是洛杉矶：白色摩天轮、黄色过山车、HOLLYWOOD、红白电视塔、铜色穹顶都在，乐高玩家会停下来看。但它更像四个元件拼在一块矩形底板上，还不像一个整体：海只是西北角的一条斜边，码头是一块空荡的大平台，海滩前景是一片光秃的沙凸点，山是平顶的台地。现在会被收藏，不会被转发。

## 5. 最重要的修改（按优先级，前五条）
1. **海岸与码头重排（维度 1、2、6、7；解掉"实物比例"和"撒点"两项不过）**：西侧和左前改成一条连续的凹弧海岸，用深蓝和沙蓝平板，外加一条暗棕褐（Dark Tan）湿沙带。浪花改成三道断续的白色线，用 1×2 / 1×1 圆头 tile 和四分之一圆 tile 排成平行于岸线的弧线。码头缩成又长又窄、垂直伸进海里的栈桥（宽约 10–12，长度过半在水上），深棕圆柱桩排架加深蓝栏杆。岛的轮廓随海岸弧线走，不再是圆角矩形。
2. **好莱坞山重塑（维度 1、2、6）**：去掉平顶和垂直台阶，用弧形斜坡、倒弧形斜坡和 2×2 / 3×3 弧形 tile 做出两三个圆峰（李山最高，电视塔在其顶），南坡做出脊和沟。字母下移到南坡、峰顶下方，站在灰色细杆上，沿等高线西低东高。灌丛改成 3–5 个一组的深绿 / 橄榄绿灌木件和叶片，沿沟谷成团，再加一条 Medium Nougat 的 1×1 圆 tile 之字形山道。天文台放到东侧一条较低的山嘴上，而不是一个平台盒子上。
3. **冲浪者与举重者（维度 4、8；解掉"穿插/抓握"不过）**：冲浪者改成双臂上举、板顶在头上（手夹夹住板边），或把板夹在腋下，手夹扣在板边；人站到湿沙线上。举重者换成真哑铃（短杆两端各一个小轮形配重），做锤式弯举；围栏换成银灰方格栅栏板，主视角那一侧放低或留开口，让他从主镜头看得见。
4. **码头甲板与前景沙滩补生活层（维度 4、6）**：甲板改成 Dark Tan 和 Reddish Brown 的 1×4 / 1×6 tile 交错拼木板纹，摆两三组人仔比例小物（长椅、街灯、小售货亭或冰淇淋车、垃圾桶）。前景沙滩把伞、毛巾、冷藏箱、沙堡（小锥和圆砖）组成一组"海滩角"，靠近救生塔，不要散开。
5. **摩天轮朝向与棕榈冠（维度 2、7）**：把摩天轮绕竖轴转到轮面正对主镜头。威尼斯棕榈的冠缩小：少用几片大叶，换成短叶片加小圆冠，读起来是细高扇叶棕榈，而不是热带椰林。

## 6. 可以保留的做法
- Technic 摩天轮、红黄交替吊舱、弧形轨过山车配彩色立柱：结构和颜色都对。
- 步道上沙蓝弧形 tile 拼的波浪纹，星光大道深色 tile 上的珊瑚星。
- 天文台：三穹顶的比例和铜色、深绿窗扇、草坪纪念碑、两侧对称。
- 滑板手站碗沿准备下碗（姿势和故事都清楚）；旱冰者的真旱冰鞋和摆臂。
- 砖搭 HOLLYWOOD 配灰腿；红白电视塔。
- 救生塔：浅蓝舱、白顶、黑色"2"、长坡道。
- 6 棵棕榈等距、同轴。
