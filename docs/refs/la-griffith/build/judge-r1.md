# 元件评审 R1 · Griffith Observatory + Hollywood Walk of Fame（LA）

评审依据：judge/JUDGE.md v4；已逐张看过 kyoto-v10 的 30 张 8 分锚点图；渲染包 j1-hero / front / side / back / top / slitdome / wing / portal / walkoffame；参考图：real-front、real-park-view、real-south-elevation、real-aerial、Miniland 两张、TheBrickPilot MOC、BenBuildsLego、概念图 la-griffith-lego.png。WebSearch：没有官方 Griffith 套装或官方 LA Architecture 套装，只有 LEGO Ideas 上的粉丝提案，所以参照用 Miniland、MOC 和概念图。

## 1. 一句话第一印象
从默认 3/4 视角**认得出是 Griffith**：后面一个大棕色穹顶，两头各一个带开缝的灰色小穹顶，中间一条白色长楼，眯眼就过。但它现在是**比例对、形体没收尾的白盒子**。小穹顶坐在方塔上（实物是圆鼓座），纪念碑是一根圆柱加金帽，看着像蜡烛或灯塔，不像方尖碑。翼楼是一整面平白墙，入口没有台阶也没有字。乐高玩家会点个赞，不会转发。

## 4. 加权总分
- 八维加权：6.5×.18 + 5.5×.15 + 5.5×.12 + 4×.15 + 7×.08 + 5×.14 + 6.5×.10 + 7.5×.08 = **5.77 ≈ 5.8**

- 门禁：**不过**。总分低于 8.0，2 / 3 / 6 维低于 7，规整审查和合规各有一条不过。
- 子项 · Walk of Fame 条带：单独看约 **6.5**。星星第一眼就认得出，印花规范。但四块星砖孤零零贴在浅灰地上，读成四张贴纸，不像一条"星光大道"。

## 5. 最重要的修改（按优先级，前三条最关键）
1. **小穹顶下改圆鼓座**（1 / 2 / 6 维，预计 +0.5～0.7）：两端的白色方塔换成 4×4 圆柱：每层四块白色"2×2 四分之一圆角砖（macaroni / round corner）"，或者直接叠白色"4×4 圆砖"。鼓座半个探出翼楼端头，就像 real-aerial 里那样。穹顶跟鼓座直径一样，不留方角。鼓座顶上加一圈白色"1×1 圆板"或"1×2 弧形光面砖"做檐口，下面开一两扇小窗。
2. **天文学家纪念碑改成方尖碑**（1 / 2 维，+0.4）：4×4 阶梯式白色基座，上面立 2×2 白砖方柱，往上用白色"1×2 / 2×2 斜坡"收成 1×1，总高约 18～20 plates，跟小穹顶差不多高。腰部四面贴白色"1×1 带侧凸点砖 + 1×2 浅浮雕砖（profile / masonry brick）"，暗示那六尊立像。顶上放一块 Pearl Gold"1×1 带杆圆板"，套一个小"环 / 方向盘件"当浑天仪。基座外圈用深绿"1×1 圆板"或"1×1 四分之一圆光面砖"围一圈绿篱，盖住现在露出来的 Dark Tan 方角。
3. **翼楼立面做 Art Deco**（3 / 6 维，+0.4～0.5）：窗之间用白色"1×2 凹槽砖（profile brick）"或 SNOT 外贴的"1×1 光面砖"做竖向壁柱。顶部一条 SNOT 白色"1×2 格栅光面砖（grille tile）"当饰带，再压一圈"1×1 板 / 倒装光面砖"挑出半格做檐口。窗退进墙面半格：深绿"1×2×3 窗框"加黑色玻璃。参照概念图和 Miniland 特写。
4. **旋转亭改成八角鼓座 + 低矮顶**（2 / 1 维，+0.2～0.3）：去掉宽盘子。Sand Green 鼓座一圈用"1×2 格栅光面砖"或 Trans-Clear"1×2 面板"做高窗；顶用 Sand Green"2×2 弧形斜坡"四向围合，或一个"4×4 穹顶 / 4×4 碟"，出檐不超过半格，顶上保留小顶饰。
5. **正门**（2 / 4 维，+0.2～0.3）：草坪路到门口加 3 级等高的浅灰平光面砖台阶。门洞外框用白色"1×1 砖"逐层退进，做出 Art Deco 阶梯门套。门洞里放 Reddish Brown 双开门（"1×2×3 面板"一对，或一扇门件）。门楣放一块印花白色"1×6 光面砖"，写 "GRIFFITH OBSERVATORY"：深铜色 Art Deco 大写无衬线，按实物的金属字做（L2，计入印花预算）。
6. **柏树换真叶子**（3 / 6 维 + 合规"树"那一条）：去掉叠起来的圆砖，改成棕色"1×1 圆砖"树干，上面叠两到三个深绿"小冷杉 2×2×4"，或者用"杆 + 尖叶植物件"一层层叉开，上窄下宽、细长。离门套墙至少 1 格。
7. **立面墙脚和后台地**（6 / 7 维，+0.2）：沿翼楼墙脚铺一条绿篱：Green"1×2 板"上放"2×2 灌木 / 带花的植物件"，实物翼楼前就有花坛（real-aerial）。后面两角的空灰铺地要么缩小台地，要么铺出路面纹样（Tan / 浅灰 2×2 光面砖拼十字缝），再放两盏灯柱。主鼓座侧面那一排排浅灰小短线要么明确做成窗（黑色"1×1 砖带格栅"），要么去掉。
8. **Walk of Fame 连成一条带**（子项，+0.5）：星砖之间用黑色"1×2 / 2×2 光面砖"补齐，连成一条连续的深色方格带，有星和无星相间，就像实物人行道上一格接一格。边缘镶一条 Pearl Gold"1×4 光面砖"或"1×1 光面砖"当铜条。第四块星砖在 j1-walkoffame 里明显比前三块亮、偏深灰：如果颜色不同就统一成 Black，如果是光照就忽略。

## 6. 可以保留的做法
- 三个高度层（28 / 20 / 13 plates），以及主穹顶和小穹顶的直径比，不要动。
- 小穹顶用同色弧形砖做成凸起的开缝罩，方向是对的，实物开缝就是凸起的。只要把底下的鼓座改圆。
- 四块草坪对称、十字路、中轴对齐，j1-top 很干净。
- 翼楼每侧 5 扇深绿高窗、Tan 屋顶平台、Sand Green 旋转亭配色、Dark Tan 台地挡墙的错缝砌法，都保留。
- 星砖印花：三色平涂、星形饱满、缩略图能读。
