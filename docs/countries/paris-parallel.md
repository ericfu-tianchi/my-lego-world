## Shared files — append only, never rewrite
- `src/core/catalog.ts`, `src/core/prints.ts`: add entries **only** by appending with a shell heredoc (`cat >> src/core/catalog.ts <<'EOF' … EOF`), one block per element with a header comment. Never open-edit-save these files (another agent may be writing). Keys prefixed by element (`nd_…`, `hc_…`, `seine_…`) unless the part is a plain LDraw mould that is not in the catalogue yet (check with grep first; if two agents add the same key, ldrawPart() replaces the earlier entry — harmless if identical).
- `src/parts/ldraw/index.ts` and `asm/index.ts` are regenerated by every `bake.mjs` run from the files on disk. If a build fails on a missing import, re-run `node tools/ldraw/bake.mjs <any id>` to regenerate them.
- Do not touch `src/scenes/lib.ts`, `index.ts`, other agents' files, or the Eiffel files. Need a grammar change? Put a local helper in your own scene file.
- Commits: do not commit; the main session commits.

## How to run
```
cd /Users/tianchifu/Desktop/lego-paris
export LDRAW_DIR="/Users/tianchifu/Desktop/My Lego World/vendor/ldraw-lib/ldraw"
node tools/ldraw/bake.mjs <ids…>                      # new moulds
npx tsx scripts/validate.ts fr-nd                       # must PASS
npx tsx scripts/check-assemblies.ts                     # if you made assemblies
npx vite build --outDir dist-nd                         # your own dir
(python3 -m http.server 8131 --directory dist-nd >/dev/null 2>&1 &)   # once
PORT=8131 node tools/shot.mjs out.png "scene=fr-nd&noglobe&only=<tag>&az=..&el=..&dist=..&tx=..&ty=..&tz=.." 900 1100
```
Camera: position = target + (sin az·c, sin el·dist, cos az·c); az 0 = +z (front), π/2 = +x. World x = grid x − W/2, z = grid z − D/2, y = plates × 0.4. `tx/ty/tz` set the target (all three or none).

## Quality bar (read CLAUDE.md first — the rules are binding)
Real LDraw moulds only; every part connects to a real stud / clip / hinge (Eric 2026-10-03 on the Eiffel arches: "哪有乐高是这么拼的" — nothing just lies on top of something); nothing interpenetrates; symmetric things symmetric; one axis; studs tiled where a real set would tile them; colours from the palette in france.md §1.4. Look at every render beside the references before calling a round done. Eric's bar: "做得越像实物越好", never rough.
