My Lego World · How it works

Real bricks, a globe, and a pipeline.

Each country is a floating LEGO island of 3,000–11,000 real parts, shown on a brick-built desk globe. This page covers the two halves: how a set gets built, and how the app presents it. Open the app.

Part 1 · Building a set

Every country follows the same playbook (docs/country-playbook.md). Three rules hold throughout:

Every part is real. Each brick maps to an actual LEGO part number and official colour, with geometry imported from the LDraw library. No invented shapes.
Everything is buildable. Every piece clicks onto a real stud, clip, hinge or pin, and nothing passes through anything else. A validator enforces this as a build gate.
Prints are code. Signs, faces and graffiti are flat vector drawings on real parts, at most 12 designs per set. No generated images in the product.

  1. Research the real place

    Pick four or five places everyone knows the city by, each paired with a minifigure doing something. Palette from photos of the real place, an island outline from its real geography, a height table for the whole set. One page, signed off before any brick.

  2. Study how others built it

    For every landmark, collect five or more existing LEGO versions (official sets, LEGOLAND Miniland, Rebrickable MOCs, LEGO Masters), note what each does for the signature detail, and identify the exact parts. If two attempts of our own fail, copy the best proven build.

  3. Blockout and scheme

    Plain boxes at each element's footprint and height, rendered from the hero camera and compared with a composition reference, so layering and scale are right before any detail. Then a level-by-level build scheme per landmark, signed off.

  4. Build elements in parallel

    Each landmark is built alone in its own test scene and git worktree, by its own agent. Angled and studs-out sub-builds are written as LDraw models, then exploded back into individual bricks so every piece stays a piece.

  5. Check, render, compare

    The gate runs a typecheck, stud-map check against each mould, assembly connection check and the validator. Close-ups from two angles catch what geometry checks cannot: a hand passing through a prop, a crooked roof.

  6. Assemble the island

    Two bricks of earth, a stone plinth, water two plates below the land, the elements placed with enforced spacing. Target 8,000 parts, hard cap 10,000.

  7. Judge, then the owner

    A judge agent scores the render pack against reference sets (Los Angeles = 9, Prague = 8), up to three rounds of fixes. The owner's own review outranks the score.

Part 2 · The app

A single-page TypeScript app on three.js, bundled with Vite and hosted on Cloudflare Pages.

Parts pipeline

tools/ldraw/bake.mjs loads each LDraw part, keeps its smooth normals, fixes the winding of mirrored parts, quantises the mesh and writes it as a compact module. The geometry ships in a few chunks so every file stays under the host's size limit.

Scenes and validator

A set is a TypeScript file that places parts on an integer grid of studs and plates. The validator rebuilds stud connectivity from the moulds and checks collisions with each part's real baked bounds.

Rendering 11,000 bricks

One instanced mesh per part type, colour and print, so a whole island draws in a few hundred calls. When the camera moves but the set does not, the shadow map is drawn once and reused, which keeps phones smooth.

The globe

A desk globe after LEGO Ideas 21332: sea tiles laid on latitude rings, coasts in round tiles, land a plate higher and mountains higher again, on a 23.4° axis in a grey meridian and a stepped stand. Dragging turns the ball, not the camera.

Entering a set

Tapping a pin turns and zooms the globe and sinks it until a sliver shows under the set. The bricks then rain in from above the screen, lowest first, each on its own eased path, on a clock that starts slow and speeds up as the zoom lands.

Take it apart

A zero-gravity burst. Under linear and angular damping each brick's flight has a closed form, x(t) = x₀ + v·(1 − e⁻ᵗ), so the burst is computed by formula instead of a physics step: smooth even at 11,000 bricks. After two seconds it hands over to a slow, endless drift. Rebuild plays the gathering in reverse.
