# 设计简报 · 中国 · 上海（形态 B · 花园式立体岛）· v1 · Eric 已认可方向（2026-10-02）；必备：东方明珠 + 三件套 + 外滩 + 石库门弄堂；与京都同尺度同气质

**一句话**：黄浦江从正中把岛一分为二，两岸隔江对望：右岸浦东，东方明珠立在江边，身后金茂、环球、上海中心一级级升高；左岸浦西，外滩一排 1920 年代花岗岩老楼沿弧形步道面江，背后一条石库门弄堂晾着衣服。深秋，浦西梧桐金黄。三个人各做一件事。

**必备特征（缺一项就不像上海）**
- 东方明珠（主角）：三根浅灰直立柱 + 三根斜撑落地，**真的球**（不是碟片）：下球约 6 studs、上球约 5、太空舱约 2，球面是洋红玻璃带夹浅灰银环；立柱间五个小球，斜撑脚下三个小球；细长分段天线约占顶部四分之一。
- 三件套：金茂（银灰，宝塔式逐级收分、越往上越密，竖向格栅肋，尖顶）；环球（沙蓝玻璃板楼收成刀刃，**顶部一个真的梯形洞**）；上海中心（最高，银蓝玻璃，圆角三角平面**一路扭转**并收分，每节一道深色带）。按真实相对位置排在明珠身后。
- 外滩：汇丰（灰色穹顶 + 鼓座 + 柱廊）、海关（多立克柱廊 + 阶梯式钟楼 + **四面白钟面**）、和平饭店（装饰艺术板楼 + **陡峭深绿铜皮金字塔顶** + 红橙收边）；三栋面江，前面是浅色花岗岩步道建在防汛墙上，一道黑栏杆，顺江的弧线走。
- 石库门弄堂：两排对面的两层排屋，中间窄弄；**深灰砖夹整层暗红砖带**、暖色石门框框着黑漆双开门、暗红半圆雕花门楣、青瓦坡顶带老虎窗和晒台；弄口一道石拱刻弄名；弄堂上空一根竹竿晾衣服。
- 黄浦江：从前缘直到后缘，中段微弯（外滩凹岸、陆家嘴凸岸）；灰绿偏浑（透明砖压沙绿 + 深灰），不是热带蓝。两岸江边做成镜像，一眼看出"一切为二"。
- 植被：法国梧桐 `tree(kind 'plane')`，树干浅灰 / 米色 / 深米色交替的**迷彩斑驳树皮**，叶子黄、亮橙、暗橙；浦西为主，浦东草坪一棵。

**生活层（人仔比例，必备）**
- 恰好 3 个人仔：外滩步道上举着红扇跳扇子舞的阿姨；弄堂里抬手晾衣服的居民；浦东滨江穿深色西装打领带的白领（一手公文包、一手咖啡或手机）。手里的东西真的握在把手上。
- 装饰件 ≤ 12 款（计划 8）：脸 3、躯干 3（运动外套、开衫、西装领带）、海关钟面（×4）、弄口石拱「步高里」。

**色板**：浦东冷色：Light Bluish Gray / Flat Silver（明珠柱和银环、金茂、上海中心）、Sand Blue + Trans-Clear（玻璃）、Magenta（只用在明珠）。浦西暖色：Tan（外滩花岗岩，待打样）、Dark Bluish Gray（石库门砖、瓦、防汛墙）、Dark Red（砖带、门楣）、Dark Green + Dark Orange（和平饭店铜顶和收边）、Black（门、栏杆）。共用：Yellow / Bright Light Orange / Dark Orange 梧桐叶、Red 扇子。**禁**：皇家黄 / 琉璃绿屋顶、大红宫墙、Dark Turquoise、热带蓝江水、龙、成排红灯笼。

**字的做法**：弄名**刻进石头再填红**（魏碑 / 楷书），不是印刷体；外滩只有钟面，不带字；浦东的楼不带字。

**尺度与布局**：岛的尺寸由各地标草图决定（Eric：宁可面积和积木数变大，也不在精致度上打折扣）；左西右东、北在后，江从前到后穿过正中；镜头从南往北顺江看。高度层：上海中心 > 环球 > 明珠 > 金茂 > 外滩钟楼 > 梧桐 > 石库门 > 人。参考图 `docs/refs/shanghai-composition.png`、`shanghai-*-lego.png`。

**禁忌**：明珠的球做成扁碟；上海中心做成直筒不扭；环球顶上没有洞；金茂做成一根方柱；外滩做成没有柱廊和钟面的米色盒子；石库门做成没有砖带和门楣的灰盒子；江水做成热带蓝；撒点当植被；空手人仔；人仔超过三个；底座卡在凸点中间；手写旋转四角。
