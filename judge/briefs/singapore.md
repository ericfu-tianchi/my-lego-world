# 设计简报 · 新加坡 · 滨海湾（形态 B · 花园式立体岛）· v1 · Eric 已认可（2026-09-18）；必备：金沙 + 擎天树 + 鱼尾狮 + 店屋/小贩摊；与京都同尺度同气质

**一句话**：一座围着滨海湾的花园岛：金沙酒店三塔顶着空中花园立在天际线，三棵擎天树是中间那层，鱼尾狮朝切进岛心的海湾喷水，螺旋桥跨过水口，一排粉彩娘惹店屋前有个小贩摊在炒锅；三个人各做一件事，岸边两只水獭。白天，湿热的绿配白与粉彩，玻璃是暗色透明。

**必备特征（缺一项就不像新加坡）**
- 滨海湾金沙（主角）：三座细高塔（浅灰体 + 暗黑透明玻璃）向内微倾，一条白色空中花园甲板横跨三塔并向北悬挑，顶上一小片透明浅蓝泳池与几点绿。
- 擎天树林：三棵高矮不同（24 / 30 / 36 板），洋红 + 深紫圆砖树干缠着绿色小植物，浅灰倒扣 4×4 碟做冠，两棵之间一条细天桥——要读成"树林"，不是路灯。
- 鱼尾狮：白色，狮头鱼身，约 9 板高，站在浅灰石板岸上，透明杆水柱落进海湾、落点几粒白水花。
- 螺旋桥：两道浅灰 1×8×2 拱跨过水口，两侧白色栏栅与 1×1 圆板交替出双螺旋节奏；读不出就换成舢板码头。
- 娘惹店屋：三开间两层，粉、天蓝、浅黄三色灰泥 + 白线脚，深橙屋瓦，二层 1×2×3 窗框 + 百叶窗扇，底层五脚基（圆砖柱下的走廊），马约利卡瓷砖一条印花带，二楼窗口伸出两根晾衣竿。
- 小贩摊：红顶开敞摊子，黄底黑字印刷体招牌「鸡饭」，炒锅（真煎锅件）架在透明橙火上，两张圆桌配红蓝 1×1 圆砖凳。
- 植被：一棵大雨树（`tree(kind 'raintree')`，扁宽伞冠、三层分叉）、两棵乐高经典椰树（2536b 树干 + 2518/6148 叶）、洋红/薰衣草兰花花坛、店屋墙边深粉三角梅。
- 水与地面：海湾从前缘切入岛心，深蔚蓝/深蓝底 + 透明浅蓝面；湾边一圈浅灰花岗岩步道，其余草坪，≥ 1/3 空。岛下两砖石基座盖顶。

**生活层（人仔比例，必备）**
- 恰好 3 个人仔：小贩围裙、前伸持煎锅、锅上有火；游客举相机对着鱼尾狮；冰淇淋大叔站在伞下推车旁、手里一支冰淇淋。手里的东西真的握在把手上。
- ≥ 10 件小物：煎锅、火、圆桌、凳、碗、招牌、推车、伞、晾衣竿、相机、两只水獭（真模具 67631）、屋顶一只八哥。
- 装饰件 ≤ 12 款（计划 10）：脸 3、躯干 3（围裙、可峇雅、T 恤）、招牌「鸡饭」、店屋牌匾（黑底金字中文 + 英文衬线）、推车侧面、马约利卡瓷砖带。

**色板**：主色 White + Light Bluish Gray，玻璃 Trans-Black；辅色 Magenta + Dark Purple（擎天树）、Dark Azure/Dark Blue 底 + Trans-Light Blue 水面、Bright Pink / Medium Azure / Bright Light Yellow 店屋 + Dark Orange 瓦；点缀 Red（摊顶、凳）、Lavender / Magenta 兰花、Dark Pink 三角梅、Green / Dark Green / Lime 植被、Tan 五脚基。**禁**：Bright Red 当主色（那是京都的）、Dark Turquoise 屋顶、第三种草绿。

**字的做法**：小贩招牌是**印刷体**黑字压黄（这里打印体才是实物）；店屋牌匾金字书法压黑 + 英文衬线；鱼尾狮与金沙不带字。

**尺度与布局**：岛 56×44；海湾从前缘切入、在岛心成潭；金沙在后右天际线，擎天树林后左，店屋与小贩摊在西岸，鱼尾狮在东岸步道朝西喷水，螺旋桥在前方水口，雨树前右，椰树夹着鱼尾狮。三个高度层：金沙（~50 板）> 擎天树（36）> 店屋（24）> 人。参考图 `docs/refs/singapore-composition.png`。

**禁忌**：把擎天树做成路灯；金沙做成三根方柱不带甲板；鱼尾狮没有水柱；店屋做成方盒子没有五脚基和百叶；撒点当植被；空手人仔；人仔超过三个；底座卡在凸点中间；手写旋转四角。
