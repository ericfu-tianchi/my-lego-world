# 设计简报 · 韩国 · 首尔（形态 B · 花园式立体岛）· v2

**一句话**：十月晴朗的下午，首尔自己的南北轴线上，依“背山临水”（배산임수）布局。后方横贯一整道山脉：左边是北岳山的花岗岩主峰，山脊上有城墙，中间一个鞍部，右肩是 N 首尔塔。中间是光化门。浅浅的广场上，BTS 回归舞台正对城门轴线。右侧北村韩屋和银杏夹着城门。最前面是汉江：骑行道、草坪上吃炸鸡喝啤酒的一对人、江上的汉江巴士。

**必备特征（缺一项就不像这里）**
- **层次（Eric 打 30 分的根本原因）**：从英雄视角（参考图机位）看，由前到后逐层升高：江 < 草坪 < 舞台（顶 = 城门台基高）< 城门（脊 50 板）< 山脉（主峰 74）；塔尖略高于主峰。山必须在城门后面露出来；城门拱洞要从舞台上方露出来；塔要立在一座和它差不多高的山上，不能比山大。
- **光化门**：花岗岩台基开三个拱洞（中间最大），两层门楼是 Dark Red 柱子和 Sand Green 斗拱带，两重庑殿顶有白色屋脊，挂“光化門”匾额，门前一对獬豸，宫墙向西一直延伸到岛边。
- **山脉**：一整道山，不是两个土包。花岗岩主峰、松林（赤松 sonamu）、山脊城墙（女墙带垛口），右肩上是塔的平台。
- **N 首尔塔**：细长白色塔身、带条纹的圆形观景舱（深色玻璃 + 浅灰楼板）、红白天线。比例按 LEGOLAND 韩国 Miniland。
- **BTS 舞台**：低矮。一面 LED 墙（暗红与灰色马赛克），两侧黑色音箱，黑色舞台上七名偶像（同一套演出服、发色统一）。台前有护栏，两名歌迷拿紫色应援棒。
- **北村**：灰瓦屋顶，瓦口是一排白色圆瓦当，白墙配木柱，花岗岩加花砖墙，巷子往下走一级级台阶，两棵金黄银杏。
- **汉江**：骑行道是 Dark Bluish Gray 加黄色中线，草坪上有路灯和长椅，花岗岩护岸向前拱出，江水 Sand Blue，汉江巴士（双体船）。

**生活层（人仔比例）**
- 守门将：红袍、黑笠、偃月刀，站在广场西侧。
- 韩服游客：粉色裙子，站在巷口面朝镜头，举着相机。
- 炸鸡啤酒的一对：坐在前左草坪的野餐垫上，各举一瓶啤酒碰杯，中间是“치킨”盒。
- 七名偶像 + 两名歌迷（舞台本身的功能需要这么多人，Eric 认可）。

**色板**：灰（Light Bluish Gray 花岗岩、Dark Bluish Gray 瓦）/ Dark Red 柱 / Dark Green 与 Green 松林 / 银杏的 Yellow / 江水 Sand Blue；点缀：Sand Green 斗拱、紫色应援棒。**禁**：鲜艳的日式朱红、Medium Azure 大面积水面、透明件整面使用。

**尺度与布局**：岛 74 × 72（Eric 同意放大：宁可变大，不在精致度上打折扣），零件 ≤ 10,000。版式按已批准的 blockout（docs/refs/seoul-island/LAYOUT-v2.md）：山脉占整个后排，城门在中间、宽约岛宽的 0.4，广场浅，舞台在前，北村在右，汉江在最前。参考图 `docs/refs/seoul-composition.png`，英雄机位 az −0.32、el 0.38。

**禁忌**：塔比它的山还大；舞台挡住城门；山被城门挡住；人仔背对镜头又说不清在干什么；拿着看不懂的东西；读不出来的漂浮物；岛的轮廓缺一块；山做成金字塔或几何台阶；日式或中式屋顶（韩屋的瓦当和屋脊是白色的）。
